# Lumina Store

Lumina is a lightweight e-commerce catalog built as a modular, client-side single-page application.

## Features

- ES modules split into data, state store, routing, UI, and application entry point
- Hash-based client-side routes for Home, Shop, About, Product Details, and Bag
- Persistent cart stored in `localStorage`
- Responsive Grid/Flexbox layouts and optimized local SVG product images
- Deployment configuration for Netlify

## Deploy

Drag this folder into Netlify Drop, or push it to GitHub and import the repository into Netlify/Vercel. No build command is required. The app uses hash routing, so it also works on GitHub Pages.
