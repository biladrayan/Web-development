# Accessible Portfolio Website

A three-page semantic HTML5 portfolio: Home, Projects, and Contact. It uses mobile-first CSS, responsive Grid and Flexbox layouts, CSS custom properties, and an accessible light/dark theme switcher.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Upload every file in this folder (`index.html`, `projects.html`, `contact.html`, and `styles.css`).
3. Optional: enable **Settings → Pages → Deploy from a branch** to publish it.

The contact form is intentionally a front-end example. Connect its `action` attribute to a form service or back-end endpoint before publishing.
